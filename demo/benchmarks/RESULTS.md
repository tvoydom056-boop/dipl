## Rerender benchmark

Автоматический CLI-замер не выполняется.
Для дипломной работы показатель рекомендуется снимать вручную через React DevTools Profiler на одинаковом сценарии:

1. Добавление задачи
2. Переключение статуса задачи
3. Изменение строки поиска
4. Переход по history snapshot

## Замечание

Текущие bundle-метрики относятся к demo-приложению целиком для каждой отдельной реализации, а не к "чистому" размеру самих библиотек в изоляции.
Для раздела про размер самой библиотеки `kiks` отдельно потребуется финальная lib-сборка пакета `packages/kiks`.
